# Clínica Laise Oliveira

Site institucional da Dra. Laise Oliveira (estética avançada — Petrolina/PE),
construído com [Next.js](https://nextjs.org) e Tailwind CSS.

## Desenvolvimento

```bash
npm install
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000).

## Build de produção

```bash
npm run build
npm run start
```

## Deploy

Projeto Next.js padrão, pronto para deploy na [Vercel](https://vercel.com).
